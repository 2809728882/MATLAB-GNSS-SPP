# 更新记录

## 2026-10-10

- 修复 RINEX 2 读取器误用 RINEX 3 记录结构、GLONASS 行索引、续行和空值处理。
- 按卫星与历元组织 GPS 数据，避免把不同时间的观测混在同一次解算中。
- 按真实 SP3 历元读取时间，转换 km→m、µs→s，识别缺失值；速度差分限定为同一卫星。
- 新增 GPS 广播轨道、卫星钟差、相对论项、L1 TGD 和信号传播期间地球旋转处理。
- 新增不依赖 Navigation Toolbox 的最小二乘接收机坐标与钟差解算。
- 新增 SP3 局部轨道插值和钟差插值，覆盖不足时跳过卫星，禁止外推。
- 精密钟差补充基于轨道插值速度的周期相对论项及配套 GPS NAV 的 L1 TGD 改正，使用 NAV 健康状态筛选卫星。
- 新增逐历元状态、伪距残差 RMS、PDOP、CSV/MAT/JSON 导出及质量曲线。
- 改为项目相对路径与显式星历模式；示例离线运行，不自动下载与观测日期无关的星历。
- 添加 MATLAB 回归测试和 GitHub Actions，包括仓库真实数据的两种星历模式。

此版本的解算范围是 **GPS L1 标准单点定位**。多星座读取和多星座联合定位是不同的功能；接收机测速、RTK、PPP、RINEX 4、精密大气与天线改正不在当前解算范围内。
